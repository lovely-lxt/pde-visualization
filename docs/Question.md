- Q1:
  53-56行这段代码：
```py
#  对角线是 2/h，上下两条副对角线是 −1/h（note0 式 (2.9)、(2.11)）
A =  (np.diag(2.0 * np.ones(N))
     - np.diag(np.ones(N - 1), 1)     # 上副对角线
     - np.diag(np.ones(N - 1), -1)) / h   # 下副对角线
F = np.ones(N) * h            # f = 1 时，F_i = h（note0 式 (2.10) 梯形积分）
```
我大概能看懂是为了构造一个三对角矩阵，并且是刚性矩阵，但语法不是很熟悉，np.ones(N)是建立一个n维向量，元素全是1，那A为什么等于()里的这些加减呢？
为什么要A除以h，F乘h，而不是A除以h^2,F乘h^2是为了缩小误差吗？

> **答（2026-09-17）**：
> - **语法**：`np.ones(N)` 是 N 个 1 的一维数组；`np.diag(v, k)` 把向量 v 放到第 k 条对角线上（k=0 主对角线，k=1 右上方一条，k=−1 左下方一条），其余位置全 0。矩阵加减是**逐元素**运算，`/h` 是每个元素都除以 h。三块拼起来 = tridiag(−1,2,−1)，除以 h 后对角线 2/h、副对角线 −1/h（N=5、h=1/6 时就是 12 和 −6）。
> - **为什么 /h 而不是 /h²**：与误差无关。两边同乘常数 h 不改变解：`(2uᵢ−uᵢ₋₁−uᵢ₊₁)/h² = fᵢ` ⟺ `(2uᵢ−uᵢ₋₁−uᵢ₊₁)/h = h·fᵢ`。选 /h 是因为**有限元推导天然长这样**：Aᵢⱼ = ∫ϕᵢ′ϕⱼ′dx = 1/h，Fᵢ = ∫fϕᵢ dx ≈ h·f(xᵢ)——第二步会亲手把这两个积分算出来。再除以 h 就变成中心差分格式 (2.14)，解不变。

- Q2：
  58行59行的代码：
```py
u_inner = np.linalg.solve(A, F)          # 解线性方程组，就是"组装求解"的最后一步
u = np.concatenate([[0.0], u_inner, [0.0]])   # 补上两个 Dirichlet 边界值 u(0)=u(1)=0
```
这是直接用库里的函数求解？因为以前学过数值代数，我大概知道有很多算法求这个三对角矩阵，比如迭代法之类的，这个库是不是就是这些已经成熟的包装好的算法库

> **答（2026-09-17）**：
> 是的。`np.linalg.solve` 底层调用 **LAPACK**（工业标准 Fortran 数值库），对一般稠密矩阵做 **LU 分解 + 部分选主元**——正是你在数值代数作业里手写过的列主元 Gauss 消去（ColumnPivotGuass.h）。所以"有限元求解"的最后一步就是数值代数的内容。N 很小时稠密 LU 足够；三对角有专用的 O(N) 追赶法（scipy 的 `solve_banded`）；二维/三维大规模稀疏系统才需要迭代法（Jacobi/GS/SOR/共轭梯度，见 74 页课件 p40–42 直接/迭代求解器）。
