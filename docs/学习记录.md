## 1. 理论地基（2026-09-17）

### 1.1 第一节课主线：把 −u″ = f 变成线性方程组 AU = F（Note0）

| 步骤 | 做法 | 关键概念 |
|---|---|---|
| ① 强形式 → 弱形式 | 乘试探函数 v，分部积分：∫u′v′dx = ∫fv dx | 导数降阶；解只需 H¹₀ 正则性；Poincaré 不等式 + Lax–Milgram ⇒ 适定 |
| ② 离散空间 | 剖分 [0,1]，允许解是分片线性折线 | hat 函数（草帽函数）ϕᵢ：ϕᵢ(xⱼ)=δᵢⱼ，**局部支撑** ⇒ 稀疏矩阵 |
| ③ Galerkin 组装 | 弱形式限制到 Vh | 刚度阵 Aᵢⱼ=∫ϕᵢ′ϕⱼ′，载荷 Fᵢ=∫fϕᵢ；均匀网格 A=(1/h)·tridiag(−1,2,−1) |
| ④ 求解 | AU = F | 解出节点值 uᵢ，连成折线就是 FEM 解 |

### 1.2 关键结论（Note0）

- **§2.4 三个身份**：均匀网格下，P1 有限元 = 中心差分 = 热方程的空间离散算子（第一步代码的主题）
- **节点精确性（Thm 3.3）**：一维常系数 Dirichlet 问题、载荷精确积分时，uh(xᵢ) = u(xᵢ)——数值解在节点上和真解完全重合（变系数/高维/数值积分就不成立了）
- **误差估计**：能量范数 O(h)（一阶）、L² 范数 O(h²)（二阶）；Galerkin 正交性 ⇒ 最佳逼近（Céa）；Ritz 法 = 能量泛函 J(v)=½∫|v′|²−∫fv 的最小化
- **P2 二次元**：升一阶——能量 O(h²)、L² O(h³)，矩阵变五对角；Simpson 凝聚
- **边界条件**：Dirichlet 是**本质**条件（加在试探空间里）；Neumann/Robin 是**自然**条件（自动出现在变分方程里）；纯 Neumann 有常数零空间，需要相容条件

### 1.3 课件绪论（dg11iq0l 第 1–2 页）

- 工程问题化为 PDE（Δu=f）后"只能近似"，两个问题：解怎么近似、误差怎么估计
- **三种近似函数**：傅里叶级数（全局光滑好）/ 全局多项式（局部好）/ **分片多项式（FEM 用这个）**，合理性由 Stone–Weierstrass 定理背书
- FEM 八步骤 + 三类误差（离散/模型/数值）
- 全学期地图：刚度法 → 杆/桁架 → 梁 → 平面 → 轴对称 → 等参 → Gauss 积分 → 板 → 非线性 → 热 → 振动 → **加权残差法**（最后一章是 FEM 与 FDM 共同的"母理论"）

## 3. 学习日志

### 2026-09-17 · 第一步：一个方程组，三个身份

- **学了什么**：矩阵 A = tridiag(−1,2,−1)/h 同时是 ① 中心差分格式 ② 均匀网格 P1 有限元刚度阵 ③ `heat_1d.py` 里热方程的空间算子。解出 AU=F 即得节点值；N=5 时节点最大误差 **2.78e-17**（机器精度）——数字验证了节点精确性。
- **代码**：新增 `poisson_1d.py`（约 100 行，注释即讲解）；产出 `output/poisson_1d_step1.png`
- **看图**：橙线抛物线 = 精确解 u=x(1−x)/2；蓝折线 = 数值解；蓝线在**节点上精确穿过橙线**（空心圆处），节点之间是直线段、误差在那里产生——这就是"分片线性近似"的字面意思
- **下一步**：载荷 Fᵢ = h·f(xᵢ) 的来历（∫fϕᵢ 的梯形积分）将在第二步用 hat 函数亲眼看到

### 2026-09-17 · 第二步：hat 基函数与组装（真正的有限元管线）

- **学了什么**：
  - ① hat 函数 ϕᵢ(x) = clip(1 − |x−xᵢ|/h)：分片线性、ϕᵢ(xⱼ)=δᵢⱼ（节点性质）、**局部支撑**（只在相邻两单元非零 ⇒ 刚度阵三对角稀疏）
  - ② 局部刚度阵：单元上两个"重心坐标" λ1=(x_k−x)/h、λ2=(x−x_{k−1})/h，导数 ±1/h ⇒ (1/h)[[1,−1],[−1,1]]——第一步矩阵的"细胞"
  - ③ 组装（Algorithm 1）：局部阵按端点编号加进全局阵（先装进含边界的 (N+2)×(N+2)，打印可见每次加在哪）；**删边界行列 = "Dirichlet 是本质边界条件"的代码实现**
  - ④ 载荷 Fᵢ = ∫fϕᵢ dx 数值积分 = h——第一步照抄的 h 找到了来历（对任意 f 都管用）
  - ⑤ 组装结果与第一步 **np.allclose 全 True**：绕远路和抄近路殊途同归
  - 细节：节点误差从第一步的 2.78e-17 变成 2.78e-10——因为载荷用了数值积分而不是精确值，**节点精确性（Thm 3.3）要求载荷精确积分**（note0 Remark 3.1 亲眼所见）
- **代码**：`poisson_1d.py` 重写为完整管线（①~⑤ 编号小节对应 note0 推导顺序）；新增 hat 函数定义与两张图
- **产出**：`poisson_1d_step2_hat.png`（草帽全家福 + 局部支撑标注）、`poisson_1d_step2.png`（u_h = Σuᵢϕᵢ 分解视图：浅蓝分量相加 = 深蓝折线）

### 2026-09-18 · 第三步：任意载荷与收敛阶

- **学了什么**：
  - ① 载荷换成任意函数 f = π²sin(πx)：挑它是因为 −u″=f、u(0)=u(1)=0 的精确解 u = sin(πx) 手算可得——有精确解才能量误差、谈收敛阶
  - ② 两个误差范数：L²（函数值差多少）与 H¹ 半范（导数差多少）。在细网格 xs 上重建 u_h = Σuᵢϕᵢ、u_h′ = Σuᵢϕᵢ′，再数值积分
  - ③ **收敛阶 = log-log 图上直线的斜率**：实测 L² 斜率 −2.00（二阶，O(h²)）、H¹ 斜率 −0.96（一阶，O(h)）——note0 误差估计亲手验证
  - ④ 数值积分要分得清主次：Fᵢ = ∫fϕᵢ 用细网格复合梯形，积分误差必须远小于 FEM 误差，否则收敛图被污染；工业标准做法是 Gauss 积分（课程地图后面有专章，先混个脸熟）
  - ⑤ 第二步的管线浓缩成函数 assemble_poisson(N, f)——同一段代码跑 5 个网格，这就是"管线"的价值
- **踩坑**：第一版 H¹ 斜率只有 −0.60，差得离谱。原因是 hat′ 定义在**开区间**上，细网格恰好在节点 xᵢ 上采样到 0（而 u_h′ 在节点上有跳跃）；每个内部节点踩一脚 ≈ 常数级误差，小 h 时把真误差（O(h)）整个盖住。改成"右连续"闭区间后（节点上取右极限 (uᵢ₊₁−uᵢ)/h），斜率立刻回到 −0.96。**教训：分片函数求导后是阶跃函数，数值积分别在跳跃点上采到"缝"里的值。**
- **代码**：`poisson_1d.py` 追加第三步（assemble_poisson / hat_prime / evaluate_uh 三个函数 + 收敛实验循环）；产出 `output/poisson_1d_step3.png`
- **看图**：左图 N=15 的折线已肉眼贴住 sin(πx)；右图 log-log 两条线各是一条直线，蓝线（L²）比橙线（H¹）陡一倍——网格加密一次，L² 误差 ÷4、H¹ 误差 ÷2
